# やること
FPGAデザインを作る

# application
LCDにテストパターンを表示する
テストパターンは7色の縦じま

## hardware
### FPGA board
Tang Primer 25K

### LCD module
Pmod-LCD-0.96-1.0

#### LCDモジュールの仕様
液晶ドライバ：ST7735S
解像度：160x80
I/F：4ラインシリアル
色深度：RGB565

## Software
### IDE GOWIN EDA
### HDL SystemVerilog

## Physical Constraint
Pmodのピン情報は次の通りです．
Pmodポートの仕様

Port1：         Pmod1　A11 CS
　　　　　　　　Pmod2　E11 MOSI
　　　　　　　　Pmod3　K11 DC
　　　　　　　　Pmod4　L5  CLK
　　　　　　　　Pmod5　A10 NC
　　　　　　　　Pmod6　E10 NC
　　　　　　　　Pmod7　L11 NC
　　　　　　　　Pmod8　K5  RESET
